# 🚀 Exercícios de Programação Orientada a Objetos (Java)
- Este repositório contém uma série de exercícios práticos desenvolvidos para consolidar os fundamentos da Programação Orientada a Objetos (POO) utilizando a linguagem Java.

## 📌 Conteúdos Abordados
- Conceitos Fundamentais: Classe, Objeto, Atributos e Métodos.

- Encapsulamento: Implementação de métodos Getters e Setters.

- Construtores: Inicialização segura de objetos.

- Lógica de Negócio: Manipulação de estados (saques, depósitos, estoque).

- Cálculos Matemáticos: Aplicação de fórmulas geométricas em objetos.

## 📂 Estrutura dos Exercícios
1. Conceitos Básicos
Explicação teórica dos pilares da POO:

- Classe: O "molde" ou planta baixa (ex: Planta de uma Casa).

- Objeto: A instância real do molde (ex: A casa construída).

- Campos (Atributos): As características (ex: cor, número de quartos).

- Métodos: As ações que o objeto realiza (ex: abrir porta).

2. Gerenciamento de Supermercado (Classe Produto)
Desenvolvimento de um sistema de estoque simples.

- Atributos: nome, preco, quantidadeEmEstoque.

- Funcionalidades: Alteração de preço, atualização de estoque e exibição de dados.

- Destaque: Uso de Construtores para garantir que nenhum produto seja criado sem nome ou preço.

3. Sistema Bancário (Classe Conta)
Simulação de operações bancárias essenciais.

- Métodos: saca(double valor), deposita(double valor) e calculaRendimento().

- Lógica: O método de rendimento aplica uma taxa de 10% sobre o saldo atual.

4. Geometria Computacional (Classes Circulo e Esfera)
Cálculos matemáticos aplicados a objetos 2D e 3D.Círculo:

- Cálculo de área ($Area = \pi \cdot r^2$).
  
- Esfera: Cálculo de volume (Volume = 4/3 x pi x r³).
  
- Uso de Math.PI: Utilização de constantes nativas do Java para precisão.

### 🧠 O que eu aprendi?
1. Encapsulamento: Entendi que Getters e Setters protegem os dados, permitindo validações futuras (como impedir que um preço seja negativo).

2. Construtores: Aprendi que eles evitam objetos "vazios" ou inconsistentes no sistema.

3. Abstração: Como transformar problemas do mundo real (um produto de mercado ou uma conta bancária) em código limpo e reutilizável.
